## What the runner may open

Allowed: raw data (MBO, trades, bars, options, roll files, `gex_levels_block1.csv`, the econ
calendar), code (`jeron_engine`, `jeron_harness`, `nt_source`, phase run scripts and configs), design
docs (engine design v3.x, fill-model proposals, the Book 1A docs and replay plan).

Not allowed (held by the separate checker session): Book 1 result files, reports, report cards,
trade lists, ledgers, fills, P&L, `phase*_results.md`, FROZEN_STRATEGY results, Phase 2-4 `run/`,
`reports/`, `review/`, `update/` folders, Phase 5 update summaries.

1. The runner read `FROZEN_STRATEGY.md` (Drive copy in the Book 1 phase3 folder) to get the exact
   C1 definition. That file also contains the Phase 3 final-combination result table (trade counts,
   net R, drawdown, verdict). The runner did not use those numbers for anything and has not opened
   any other result file, but this counts as a blinding exposure and is logged here and in the
   Phase 0 report. Recommendation: the checker, not the runner, should hold `FROZEN_STRATEGY.md`
   in future; the C1 definition alone should be copied into a results-free file.
2. The Book 1A phase docs themselves quote Book 1 Phase 2 / Phase 3 per-arm results (for example
   RH1 +0.888 R per session). Those are in the docs the runner was told to read; noted, not avoidable.
3. The engine design doc v3.10 "what changed" log quotes Phase 2 A0 totals and exit-model first
   looks. Same note.

## Blind-run mechanics for the PC run

- Run from a fresh folder: `K:\Databento_BackTesting\Book1A\` with `book1a/` checked out at the tag
  `book1a-phase0-freeze`; `PYTHONPATH` points at `book1a` and `book1_ref` only.
- The run reads `raw\block1`, the roll files, `gex_levels_block1.csv`, the econ calendar and the
  packets it builds itself. It never reads `backtest\phase2`, `phase3`, `phase4` outputs.
- Book 1 result folders stay where they are (frozen, untouched); the runner's process only needs
  read access to `raw\`, `jeron_engine\`, `jeron_harness\` and the static input files.
